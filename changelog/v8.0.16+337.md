- Renamed to JHenTaiX: bundle id / applicationId are now top.jtmonster.jhentaix, with the app and artifact names updated on macOS, Windows, Android and Linux
- Icon background recolored from #E6E623 to teal #0FA3A3; the artwork itself is untouched, so it stays easy to tell apart from upstream JHenTai
- The two apps are now independent and can be installed side by side, and no longer share settings or the gallery database
- Note for Android: this is a different application id, so it will not upgrade in place from an older build -- reinstall and sign in again
